# gRPC adapter

The inbound adapter for gRPC. Template: `assets/templates/grpc/`.

## Files

| Path | Holds |
|---|---|
| `api/proto/<service>/v1/<entity>.proto` | the contract |
| `internal/infrastructure/api/grpc/grpc.go` | `//go:generate`, `Service` interface, `Server`, `New`, `Register`, RPCs, `toStatus` |
| `…/grpc/mappers.go` | `mapDomain<Entity>(req)`, `map<Entity>Message(e)`, `mapBadRequest` |
| `…/grpc/validation.go` | `validate<Rpc>Request(req) []domain.Violation` |
| `…/grpc/pb/` | generated by `go generate`; never edited, never checked |

There is no `dto.go`: the generated messages are the DTOs. Methods cannot be added
to generated types, so conversions in **both** directions are `map<Target>`
functions in `mappers.go`:

```go
func mapDomainUser(req *pb.CreateUserRequest) domain.User { … }
func mapUserMessage(e domain.User) *pb.User { … }
```

## Generating

```go
//go:generate protoc --proto_path=../../../../api/proto --go_out=../../../.. --go_opt=module=<module> --go-grpc_out=../../../.. --go-grpc_opt=module=<module> <service>/v1/<entity>.proto
```

Needs `protoc`, `protoc-gen-go` and `protoc-gen-go-grpc` on `PATH`. Run
`go generate ./internal/infrastructure/api/grpc/` before `go mod tidy`, since `tidy`
needs the `pb` package to exist. Commit the generated files.

## The proto

- `package <service>.v1;` and a `v1` directory. A breaking change is a new `v2`.
- Response messages omit secret fields; request messages carry them.
- Field numbers are forever. Never reuse a removed one; mark it `reserved`.
- `int` in the domain is `int64` in proto. Time is `google.protobuf.Timestamp`, mapped
  with `timestamppb.New` and `.AsTime()`.

## An RPC

```go
func (s *Server) CreateUser(ctx context.Context, req *pb.CreateUserRequest) (*pb.User, error) {
	if violations := validateCreateUserRequest(req); len(violations) > 0 {
		return nil, s.toStatus(ctx, domain.Invalid(violations...))
	}
	user, err := s.svc.CreateUser(ctx, mapDomainUser(req))
	if err != nil {
		return nil, s.toStatus(ctx, err)
	}
	return mapUserMessage(user), nil
}
```

Same shape as a REST handler: validate shape, call the use case, map. Every error goes
through `toStatus`, which picks the code, logs `Internal` errors only, and attaches
violations as `errdetails.BadRequest`. Validation is covered in `validation.md`, the
code table in `errors.md`.

## Serving

`main.go` listens on `GRPC_ADDR`, runs the gRPC server beside HTTP, and calls
`GracefulStop` on shutdown. The adapter package is named `grpc`; import it as
`grpcapi` in `main.go` to keep `google.golang.org/grpc` readable.
